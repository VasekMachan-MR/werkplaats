Jak obnovit Werkplaats a E-servisku

Návod pro případ, že by se cokoli ztratilo nebo rozbilo. Záloha z 30. 10. 2026.

Nejjednodušší cesta (doporučeno): otevři Clauda (aplikace Claude na Macu), propoj ho s Macem a napiš:
„Obnov prosím Werkplaats a E-servisku ze zálohy v iCloudu: Mercedes Restorations → Zálohy Werkplaats → (nejnovější datum). Postupuj podle souboru JAK-OBNOVIT.html.“
Claude udělá všechno sám. Ty jen potvrdíš přístupy a jednou se přihlásíš.

4. Nová databáze (jen když Supabase projekt zmizel)

  1. Na supabase.com se přihlas → New project → region Central EU (Frankfurt) → vytvořit.
  2. Vlevo SQL Editor → New query.
  3. Rozbal kód: v Terminálu na Macu napiš git clone "cesta/k/werkplaats-kod-….bundle" werkplaats. Nebo si soubory stáhni z GitHubu (zelené tlačítko Code → Download ZIP).
  4. Ve složce databaze otevírej soubory 001_…sql, 002_…, … přesně v pořadí podle čísla (015 před 015b, 028 před 028b). Obsah každého vlož do SQL Editoru a klikni Run. Musí napsat „Success“.
  5. Authentication → Providers → Email nech zapnuté. Authentication → Multi-Factor zapni TOTP.
  6. Authentication → URL Configuration: Site URL https://werk.mercedesrestorations.cz, Redirect URL https://werk.mercedesrestorations.cz/**.
  7. Storage: koš soubory vytvořil už skript 005, nic dalšího se nedělá.
  8. Edge Functions: pro každou složku v databaze/funkce/ (eserviska, kurz-cnb, smazat-soubory, sprava-uzivatelu) → Deploy new function se stejným názvem a vložit obsah index.ts. U eserviska vypnout „Verify JWT“, u ostatních nechat zapnuté.
  9. Nový projekt má novou adresu a klíč: Project Settings → API. Adresu a „publishable key“ přepiš v souboru aplikace/nastaveni.js. Adresu přepiš i v web/e-serviska-footer.html (řádek var API=…).

5. Nahrát data zpátky

Nejdřív se jednou přihlas do aplikace (vytvoř si účet se svým e-mailem). Skript tvůj nový účet pozná a dá mu roli majitele.
  1. Supabase → SQL Editor → New query.
  2. Otevři data/obnova-dat.sql (třeba v TextEditu), označ všechno (⌘A), zkopíruj (⌘C) a vlož do editoru (⌘V).
  3. Klikni Run. Na konci se objeví „Obnova dat dokončena“.

Skript nejdřív smaže, co v tabulkách je, a nahraje data ze zálohy. Vyzkoušeno 30. 10. 2026 na čisté databázi: všech 10 zakázek, 9 zákazníků, 9 aut, 37 dílů, doklady, podpisy i nastavení se nahrály.

6. Aplikace Werkplaats (Cloudflare)

  1. dash.cloudflare.com → Workers & Pages → projekt werkplaats. Pokud chybí: Create → Pages → Connect to Git → GitHub VasekMachan-MR/werkplaats.
  2. Nastavení: Production branch main, Build command npm run build, Build output dist.
  3. Custom domains → werk.mercedesrestorations.cz.
  4. Každá změna kódu na GitHubu (větev main) se nasadí sama za 1–2 minuty.

7. E-serviska na webu (Webflow)

  1. Webflow → web Mercedes Restorations → Pages → stránka E-serviska (adresa /e-serviska). Pokud chybí, vytvoř prázdnou stránku s tímto názvem a adresou.
  2. Ozubené kolečko stránky → Custom code:
    • Inside <head> tag ← celý obsah souboru web/e-serviska-head.html
    • Before </body> tag ← celý obsah souboru web/e-serviska-footer.html
  3. SEO title: E-servisní knížka | Mercedes Restorations, description: Servisní historie vozu Mercedes-Benz z dílny Mercedes Restorations.
  4. Publish na obě domény (mercedesrestorations.cz i www).

8. Fotky, videa a PDF (Cloudflare R2)

  1. Kopie všech souborů je v Cloudflare: R2 → koš werkplaats-soubory. Složky jsou stejné jako v Supabase (zakazky/7377/…, dokumenty/tp/…, archiv/…).
  2. Obnova = nahrát obsah koše R2 zpátky do Supabase → Storage → soubory se stejnými cestami. Nejrychleji: napiš Claudovi „nahraj soubory z R2 werkplaats-soubory do Supabase Storage soubory“. Ručně: v Supabase Storage přetáhnout složky stažené z R2.
  3. Které soubory k čemu patří, ví databáze (tabulka soubory, sloupec klic = cesta souboru). Po nahrání dat i souborů se všechno samo propojí.

9. Kontrola, že vše funguje

  • werk.mercedesrestorations.cz → přihlášení (heslo + kód z aplikace) → v Zakázkách vidím zakázky, fotky a PDF jdou otevřít.
  • Otevřít odkaz na E-servisku u některého auta (Vozidlo → „Odkaz na E-servisku“) → stránka se načte i s fotkami.

10. Jak často se zálohuje

  • Kód: GitHub drží každou změnu. Do iCloudu se dává balíček při každé větší záloze.
  • Databáze: Supabase Pro dělá zálohu každý den (7 dní zpátky). Tenhle balíček je k tomu navíc mimo Supabase.
  • Fotky a PDF: zrcadlo v Cloudflare R2.
